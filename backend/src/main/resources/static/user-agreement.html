二、服务说明

2.1 服务内容

和信数智健康是一个智能健康管理平台，为您提供以下服务：

  • 健康数据管理：上传、存储、查看医疗报告、就诊记录、皮肤照片等健康数据
  • 运动健康数据同步：通过华为运动健康服务同步步数、心率、睡眠等运动健康数据
  • 健康档案生成：自动整理您的健康数据，生成个人健康档案
  • 健康分析：基于您的健康数据提供健康分析和建议
  • 其他相关健康管理服务

我们有权根据业务发展需要调整、变更或终止部分或全部服务内容，并会提前通知您。如您不同意变更内容，可以停止使用相关服务。
