# 运动识别项目 - 使用说明

本文档详细说明如何下载数据、训练模型、实时识别，以及如何保留多个训练版本。

---

## 一、快速开始

```powershell
# 1. 安装依赖
pip install -r requirements.txt

# 2. 下载数据集 (需先设置 ROBOFLOW_API_KEY)
python scripts/download_dataset.py

# 3. 训练
python scripts/train.py

# 4. 摄像头识别
python run_camera.py
```

---

## 二、数据集下载

### 2.1 获取 API Key

1. 访问 [Roboflow](https://app.roboflow.com) 登录
2. 进入 **Account Settings → API** 复制 API Key
3. 在 [exercise-ekbld 数据集页](https://universe.roboflow.com/activityrecognition-noyo4/exercise-ekbld) 点击 **Fork Dataset** 到你的工作区

### 2.2 下载命令

```powershell
set ROBOFLOW_API_KEY=你的API密钥
python scripts/download_dataset.py
```

可选环境变量：
- `ROBOFLOW_PROJECT`：项目 ID（默认 `exercise-ekbld-kjve3`）
- `ROBOFLOW_WORKSPACE`：工作区（不设则使用默认）

---

## 三、模型训练

### 3.1 基本训练

```powershell
python scripts/train.py
```

输出目录：`runs/exercise_train/`，模型：`runs/exercise_train/weights/best.pt`

### 3.2 使用不同 TRAIN_NAME 保留旧模型

每次训练使用不同名称，会生成新目录，**不会覆盖**已有模型：

```powershell
set TRAIN_NAME=exercise_train_v2
python scripts/train.py
```

- 第一次训练：默认 `TRAIN_NAME=exercise_train` → `runs/exercise_train/`
- 第二次训练：`TRAIN_NAME=exercise_train_v2` → `runs/exercise_train_v2/`
- 第三次训练：`TRAIN_NAME=exercise_train_v3` → `runs/exercise_train_v3/`

每次训练都会生成独立目录，旧模型保持不变。

### 3.3 训练可选参数

| 环境变量 | 说明 | 默认值 |
|----------|------|--------|
| `TRAIN_NAME` | 本次训练目录名，不同值保留不同版本 | `exercise_train` |
| `EPOCHS` | 训练轮数 | `100` |
| `BATCH` | 批次大小 | `16` |
| `DEVICE` | 设备：`0`=GPU，`cpu`=CPU | `0` |
| `TENSORBOARD` | 是否启用 TensorBoard：`1`=是，`0`=否 | `1` |

示例：

```powershell
set TRAIN_NAME=exercise_train_100ep
set EPOCHS=100
set BATCH=16
set DEVICE=0
python scripts/train.py
```

### 3.4 TensorBoard 监控

训练默认开启 TensorBoard，可按以下步骤查看曲线：

**① 安装**（若未安装）
```powershell
pip install tensorboard
```

**② 训练时另开终端，启动 TensorBoard**
```powershell
cd D:\ai-exercise-train
tensorboard --logdir runs --port 6006
```
或双击 `scripts/start_tensorboard.bat`

**③ 浏览器访问**
```
http://localhost:6006
```

## 四、摄像头实时识别

### 4.1 基本使用

```powershell
python run_camera.py
```

程序会按顺序查找模型：
1. `runs/exercise_train/weights/best.pt`
2. `runs/<任意 TRAIN_NAME>/weights/best.pt`（取最新一次训练）

### 4.2 指定模型

使用自定义 `TRAIN_NAME` 训练后，可指定模型路径：

```powershell
python run_camera.py --model runs/exercise_train_v2/weights/best.pt
```

### 4.3 其他参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `--model` | 模型路径 | `--model runs/exercise_train_v2/weights/best.pt` |
| `--weight` | 体重(kg) | `--weight 70` |
| `--height` | 身高(cm) | `--height 170` |
| `--camera` | 摄像头索引 | `--camera 0` |
| `--no-pose` | 禁用次数计数 | `--no-pose` |

按键：
- `q`：退出
- `r`：重置当前运动次数

## 五、训练版本管理示例

| 操作 | 命令 | 结果 |
|------|------|------|
| 第一次训练 | `python scripts/train.py` | 生成 `runs/exercise_train/` |
| 第二次训练（保留旧版） | `set TRAIN_NAME=exercise_train_v2`<br>`python scripts/train.py` | 生成 `runs/exercise_train_v2/`，旧版保留 |
| 使用 v2 模型 | `python run_camera.py --model runs/exercise_train_v2/weights/best.pt` | 使用 v2 模型识别 |
| 使用最新模型 | `python run_camera.py` | 自动选用最新训练的 `best.pt` |

## 六、配置文件

`config/exercise_config.yaml` 可修改：

- **user_profile**：默认体重、身高
- **exercise_met_values**：各运动 MET 值（用于卡路里计算）
- **rep_count_configs**：各运动姿态关键点与角度阈值（用于次数计数）

## 七、常见问题

**Q: 训练中断后如何继续？**  
A: 可用 `runs/<名称>/weights/last.pt` 进行推理，或参考项目说明配置断点续训。

**Q: 如何比较不同版本模型？**  
A: 用不同 `TRAIN_NAME` 训练多个版本，通过 `--model` 切换运行对比。

**Q: TensorBoard 没有数据？**  
A: 确认训练已开始，且环境变量未设置 `TENSORBOARD=0`。

**Q: 卡路里如何计算？**  
A: 公式为 `体重(kg) × MET × 时长(小时)`，MET 在 `exercise_config.yaml` 中配置。
