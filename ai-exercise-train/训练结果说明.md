# 训练结果说明

## 一、最终验证指标

训练结束时输出的 `squats 22 22 0.927 0.909 0.983 0.76` 表示：

| 列名 | 含义 | 示例值 |
|------|------|--------|
| Class | 类别名称 | squats (深蹲) |
| Images | 验证集中该类别的图片数 | 22 |
| Instances | 该类别的目标框总数 | 22 |
| **P** | Precision (精确率) | 0.927 (92.7%) |
| **R** | Recall (召回率) | 0.909 (90.9%) |
| **mAP50** | IoU=0.5 时的 mAP | 0.983 (98.3%) |
| **mAP50-95** | IoU 0.5~0.95 平均 mAP | 0.76 (76%) |

**整体准确率**：通常以 **mAP50** 或 **mAP50-95** 作为综合指标。你当前模型整体约 **92% mAP50**（见 results.csv 第 100 行）。

## 三、输出图片含义

训练完成后，`runs/exercise_train/` 目录下通常会有：

| 文件 | 含义 |
|------|------|
| **results.png** | 训练曲线：Loss、Precision、Recall、mAP 随 epoch 变化 |
| **confusion_matrix.png** | 混淆矩阵：各类别预测 vs 真实标签，看误检/漏检 |
| **confusion_matrix_normalized.png** | 归一化混淆矩阵 |
| **F1_curve.png** | F1 分数 vs 置信度阈值，用于选最佳 conf |
| **P_curve.png** | Precision vs 置信度 |
| **R_curve.png** | Recall vs 置信度 |
| **PR_curve.png** | Precision-Recall 曲线 |
| **labels.jpg** | 数据集标签分布（框的尺寸、位置） |
| **labels_correlogram.jpg** | 类别相关性 |

## 四、指标解读

- **Precision 高**：预测为某类时，多数是对的，误报少  
- **Recall 高**：真实目标大多能被检出，漏检少  
- **mAP50 高**：整体检测质量好（IoU>0.5 即算正确）  
- **mAP50-95 高**：定位更准，框更贴合目标  

你当前 mAP50≈92%，说明在验证集上表现良好，可用于实际识别。
