# 快乐生活小程序

基于 uni-app + Vue 开发的健康管理类微信小程序。

## 项目说明

这是一个健康管理类小程序的前端静态页面，实现了完整的UI界面，暂不包含后端接口调用。

## 技术栈

- **框架**: uni-app (Vue 2)
- **UI组件**: uni-icons (uni-app 官方图标组件)
- **开发工具**: HBuilderX
- **目标平台**: 微信小程序

## 项目结构

```
快乐生活/
├── pages/              # 页面目录
│   ├── index/         # 首页
│   ├── manage/        # 康乐管理
│   ├── hospital/      # 就医服务
│   ├── mall/          # 商城
│   └── profile/       # 我的
├── static/            # 静态资源
│   └── tabbar/        # 底部导航栏图标
├── App.vue            # 应用入口
├── main.js            # 主入口文件
├── manifest.json      # 应用配置
└── pages.json         # 页面路由配置
```

## 功能模块

### 1. 首页 (pages/index/index.vue)

- **顶部导航栏**: 菜单、标题、AI助手、语音、更多选项
- **介绍区域**: "我是康乐"标题、副标题、医生插画
- **我的健康卡片**: 三个功能图标、开启按钮
- **任务和推荐卡片**: 待打卡任务、医生推荐、健康问答
- **服务网格**: 8个服务图标（智能、健康小目标、AI诊室、拍皮肤、就医服务、药管家、拍报告、快乐活动）
- **聊天输入栏**: 语音输入、文本输入、更多功能、拍照

### 2. 其他页面

- 康乐管理 (pages/manage/manage.vue)
- 就医服务 (pages/hospital/hospital.vue)
- 商城 (pages/mall/mall.vue)
- 我的 (pages/profile/profile.vue)

## 使用说明

### 1. 安装依赖

项目使用 uni-app，无需额外安装依赖。uni-icons 是 uni-app 内置组件，直接使用即可。

**重要**: 本项目完全使用 uni-icons 组件，**不需要任何额外的图片资源**。

### 2. 运行项目

在 HBuilderX 中：
1. 打开项目
2. 运行 → 运行到小程序模拟器 → 微信开发者工具

### 3. 配置微信开发者工具

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 在 HBuilderX 中配置微信开发者工具路径：
   - 工具 → 设置 → 运行配置 → 微信开发者工具路径

### 4. 底部导航栏

底部导航栏使用纯文字模式，不依赖图片资源。所有图标都使用 uni-icons 组件实现。

## 样式说明

- **主色调**: 绿色渐变 (#07C160 → #06A050)
- **辅助色**: 蓝色 (#1890ff)、紫色 (#722ed1)
- **背景色**: 白色、浅灰色 (#f5f5f5)
- **圆角**: 统一使用 16-24rpx
- **阴影**: 卡片使用轻微阴影效果

## 注意事项

1. **uni-icons 组件**: 项目完全使用 uni-app 官方的 uni-icons 组件，这是内置的，无需安装，**不需要任何图片资源**
2. **底部导航栏**: 使用纯文字模式，不依赖图片，所有图标都通过 uni-icons 实现
3. **事件处理**: 所有点击事件已实现，目前显示 Toast 提示，实际功能需要后续开发
4. **样式单位**: 使用 `rpx` 响应式单位，适配不同屏幕尺寸
5. **聊天输入栏**: 固定在底部（距离底部 100rpx），注意页面滚动时的显示效果
6. **医生插画**: 使用 uni-icons 的 `staff` 图标代替，无需额外图片

## 编译和发布

### 编译为微信小程序

在 HBuilderX 中：
```
发行 → 小程序-微信
```

编译后的文件在 `unpackage/dist/dev/mp-weixin/` 目录

### 上传和发布

1. 使用微信开发者工具打开编译后的文件夹
2. 点击"上传"按钮，填写版本号和项目备注
3. 登录微信公众平台，提交审核
4. 审核通过后，点击"发布"即可上线

## 开发建议

1. **使用 uni-ui**: 如果需要更多组件，可以安装 uni-ui 组件库
2. **使用 iconfont**: 对于自定义图标，可以使用 iconfont 图标字体
3. **代码规范**: 遵循 Vue 和 uni-app 的代码规范
4. **性能优化**: 注意图片大小、避免过度渲染等
