# 底部导航栏图标说明

## 需要的图标文件

在 `static/tabbar/` 目录下需要以下图标文件：

### 1. 首页图标
- `home.png` - 普通状态（灰色）
- `home-active.png` - 选中状态（绿色 #07C160）

### 2. 康乐管理图标
- `manage.png` - 普通状态
- `manage-active.png` - 选中状态

### 3. 就医服务图标
- `hospital.png` - 普通状态
- `hospital-active.png` - 选中状态

### 4. 商城图标
- `mall.png` - 普通状态
- `mall-active.png` - 选中状态

### 5. 我的图标
- `user.png` - 普通状态
- `user-active.png` - 选中状态

## 图标规格

- **尺寸**: 建议 40x40px 或 81x81px（2倍图）
- **格式**: PNG（支持透明背景）
- **颜色**: 
  - 普通状态: #7A7E83（灰色）
  - 选中状态: #07C160（绿色）

## 快速获取图标的方法

### 方法一：使用在线图标库

1. **IconFont** (https://www.iconfont.cn/)
   - 搜索需要的图标（如：首页、管理、医院、商城、用户）
   - 下载 PNG 格式
   - 调整颜色和尺寸

2. **IconPark** (https://iconpark.oceanengine.com/)
   - 提供丰富的图标
   - 支持自定义颜色和尺寸

### 方法二：使用图标生成工具

1. **Canva** (https://www.canva.com/)
   - 创建简单的图标设计
   - 导出为 PNG

2. **Figma** (https://www.figma.com/)
   - 专业设计工具
   - 可以精确控制图标样式

### 方法三：临时占位符

如果暂时没有图标，可以创建简单的占位符：

1. 使用纯色方块
2. 使用文字（如：首、管、医、商、我）
3. 使用 Emoji（但小程序可能不支持）

## 图标设计建议

- **风格统一**: 所有图标使用相同的设计风格
- **简洁明了**: 图标要清晰易懂
- **对比度**: 确保在白色背景上清晰可见
- **尺寸一致**: 所有图标使用相同的尺寸

## 注意事项

- 如果没有图标文件，底部导航栏会显示空白
- 图标路径在 `pages.json` 的 `tabBar` 配置中
- 确保图标文件路径正确，否则无法显示
