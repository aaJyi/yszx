# 智能体查询原始数据和基本信息接口文档

## 一、接口概述

本接口用于智能体开发程序员获取用户的完整数据，包括：
- 该用户的所有原始健康数据（体检报告、就诊记录等）
- 该用户的所有健康档案及其所有从表数据（个人健康标识、用户基本信息、过敏史、既往史等）

**设计优势**：
- ✅ **一次接口调用**即可获取用户的所有相关数据
- ✅ 后端自动查询并关联所有相关数据
- ✅ 智能体无需关心数据关联关系，直接使用即可

---

## 二、接口详情

### 接口地址

```
GET /health-ai-analysis/data/user/{userId}
```

### 完整URL示例

```
GET https://43d51924.r16.vip.cpolar.cn/health-ai-analysis/data/user/2
```

### 请求方式

`GET`

### 请求参数

| 参数名 | 类型 | 位置 | 必填 | 说明 |
|--------|------|------|------|------|
| userId | Long | 路径参数 | 是 | 用户ID |

### 请求示例

#### Python示例

```python
import requests

# 只需传递userId，后端自动查询所有相关数据
user_id = 2
url = f"https://43d51924.r16.vip.cpolar.cn/health-ai-analysis/data/user/{user_id}"

response = requests.get(url)
if response.status_code == 200:
    result = response.json()
    if result.get('code') == 200:
        data = result.get('data', {})
        
        # 获取原始健康数据列表
        raw_health_data_list = data.get('rawHealthDataList', [])
        print(f"获取原始数据：{len(raw_health_data_list)}条")
        
        # 获取健康档案列表（每个档案包含所有从表数据）
        health_archives = data.get('healthArchives', [])
        print(f"获取健康档案：{len(health_archives)}个")
        
        # 遍历健康档案
        for archive in health_archives:
            archive_info = archive.get('healthArchive', {})
            archive_id = archive_info.get('archiveId')
            user_info = archive.get('userInfo', {})
            allergy_history = archive.get('allergyHistory')
            disease_history = archive.get('diseaseHistory')
            family_history = archive.get('familyHistory')
            # ... 其他从表数据
            print(f"档案ID：{archive_id}，用户名：{user_info.get('fullName')}")
    else:
        print(f"获取数据失败：{result.get('message')}")
else:
    print(f"请求失败：{response.status_code}")
```

#### cURL示例

```bash
curl -X GET "https://43d51924.r16.vip.cpolar.cn/health-ai-analysis/data/user/2" \
  -H "Content-Type: application/json"
```

## 五、使用场景

### 场景1：获取用户原始体检报告

```python
# 获取用户完整数据
response = requests.get(f"{BASE_URL}/health-ai-analysis/data/user/{user_id}")
data = response.json().get('data', {})

# 筛选体检报告类型的原始数据
raw_health_data_list = data.get('rawHealthDataList', [])
report_data = [item for item in raw_health_data_list if item.get('dataType') == 'REPORT']

# 下载体检报告文件进行OCR分析
for report in report_data:
    file_url = report.get('fileUrl')
    # 下载文件并进行OCR处理
    # ...
```

### 场景2：结合健康档案信息进行分析

```python
# 获取用户完整数据
response = requests.get(f"{BASE_URL}/health-ai-analysis/data/user/{user_id}")
data = response.json().get('data', {})

# 获取健康档案
health_archives = data.get('healthArchives', [])
if health_archives:
    archive = health_archives[0]
    
    # 获取家族史信息（影响风险等级评估）
    family_history = archive.get('familyHistory')
    if family_history:
        print(f"家族史：{family_history.get('diseaseName')}")
    
    # 获取既往史信息（影响分析结论）
    disease_history = archive.get('diseaseHistory')
    if disease_history:
        print(f"既往史：{disease_history.get('diseaseName')}")
    
    # 获取个人健康标识（影响参考范围）
    profile_tags = archive.get('healthProfileTags', {})
    if profile_tags.get('isElderly65'):
        print("65岁以上老人，需要调整参考范围")
    if profile_tags.get('isPregnant'):
        print("孕产妇，需要调整参考范围")
```

## 六、注意事项

### 1. 数据完整性

- ✅ 一次接口调用即可获取用户的所有相关数据
- ✅ 后端自动查询并关联所有从表数据
- ✅ 如果某个从表没有数据，对应字段可能为 `null` 或空对象

### 2. 数据使用建议

- **原始健康数据**：用于OCR/图像识别，提取体检指标数据
- **健康档案基本信息**：用于了解用户的基本情况
- **既往史、家族史**：用于调整风险等级评估
- **个人健康标识**：用于确定人群分组和参考范围

### 3. 性能考虑

- 如果用户有大量健康档案和原始数据，响应数据可能较大
- 建议智能体按需处理数据，不需要的数据可以忽略

### 4. 错误处理

- 如果用户ID不存在，会返回空列表
- 如果用户没有健康档案，`healthArchives` 为空数组
- 如果用户没有原始数据，`rawHealthDataList` 为空数组

## 八、完整调用示例

```python
import requests
from typing import Dict, Any

BASE_URL = "https://43d51924.r16.vip.cpolar.cn"

def get_user_complete_data(user_id: int) -> Dict[str, Any]:
    """
    获取用户完整数据（原始数据 + 健康档案）
    
    参数:
        user_id: 用户ID
    
    返回:
        用户的完整数据字典
    """
    url = f"{BASE_URL}/health-ai-analysis/data/user/{user_id}"
    response = requests.get(url)
    
    if response.status_code == 200:
        result = response.json()
        if result.get('code') == 200:
            return result.get('data', {})
        else:
            raise Exception(f"获取用户完整数据失败：{result.get('message')}")
    else:
        raise Exception(f"请求失败：{response.status_code}")

# 使用示例
if __name__ == "__main__":
    user_id = 2
    
    try:
        # 获取用户完整数据
        complete_data = get_user_complete_data(user_id)
        
        # 提取原始健康数据
        raw_health_data_list = complete_data.get('rawHealthDataList', [])
        print(f"原始数据：{len(raw_health_data_list)}条")
        
        # 提取健康档案
        health_archives = complete_data.get('healthArchives', [])
        print(f"健康档案：{len(health_archives)}个")
        
        # 处理第一个健康档案
        if health_archives:
            archive = health_archives[0]
            archive_info = archive.get('healthArchive', {})
            print(f"档案ID：{archive_info.get('archiveId')}")
            print(f"档案名称：{archive_info.get('archiveName')}")
            
            # 获取用户基本信息
            user_info = archive.get('userInfo', {})
            print(f"用户姓名：{user_info.get('fullName')}")
            print(f"性别：{user_info.get('gender')}")
            
            # 获取家族史
            family_history = archive.get('familyHistory')
            if family_history:
                print(f"家族史：{family_history.get('diseaseName')}")
            
            # 获取既往史
            disease_history = archive.get('diseaseHistory')
            if disease_history:
                print(f"既往史：{disease_history.get('diseaseName')}")
        
    except Exception as e:
        print(f"处理失败：{str(e)}")
```

## 九、相关接口

### 1. 获取健康档案详情（单独调用）

如果需要单独获取某个健康档案的详情，可以使用：

```
GET /health-archive-process/detail/{archiveId}
```

### 2. 获取原始健康数据（单独调用）

如果需要单独获取某条原始健康数据，可以使用：

```
GET /raw-health-data/{id}
```

**注意**：本接口（`/health-ai-analysis/data/user/{userId}`）已经包含了上述两个接口的所有数据，通常不需要单独调用。

## 十、总结

本接口为智能体开发程序员提供了**一站式数据获取**功能：

✅ **简化调用**：一次接口调用获取所有数据  
✅ **数据完整**：自动关联所有从表数据  
✅ **易于使用**：智能体无需关心数据关联关系  
✅ **性能优化**：后端统一查询，减少网络请求次数

智能体可以直接基于返回的数据进行AI分析，无需多次调用接口。
