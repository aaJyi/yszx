# 健康数据查询接口文档

## 接口概述

本接口用于查询指定用户的所有健康数据，返回的数据包含二进制文件（Base64编码），供智能体模块分析和生成健康档案使用。

---

## 接口信息

### 1. 查询用户所有健康数据

**接口路径：**
```
GET /raw-health-data/user/{userId}
```

**请求方式：** `GET`

**Content-Type：** `application/json`

---

## 请求参数

### 路径参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| userId | Long | 是 | 用户ID，路径参数 |

**示例：**
```
GET /raw-health-data/user/1
```

---

## 数据类型说明（dataType）

| 值 | 说明 |
|----|------|
| REPORT | 拍报告（医疗报告图片） |
| MEDICAL_RECORD | 就诊记录（图片或PDF文档） |
| SKIN | 拍皮肤（皮肤照片） |
| WEARABLE | 可穿戴设备数据（JSON格式） |
| LAB | 检查检验（检验报告图片） |
| EMOTION | 情绪检测（情绪相关图片） |
| GENETIC | 基因检测（基因检测报告图片） |
| SLEEP | 睡眠监测（JSON格式数据） |
| MEAL | 拍三餐（饮食照片） |
| EXERCISE | 运动数据（JSON格式数据） |

---

## 格式类型说明（formatType）

| 值 | 说明 | rawData内容 |
|----|------|-------------|
| IMAGE | 图片格式（JPEG/PNG等） | Base64编码的图片二进制数据 |
| PDF | PDF文档 | Base64编码的PDF文件二进制数据 |
| JSON | JSON格式数据 | Base64编码的JSON字符串（需要先Base64解码，再JSON解析） |
| CSV | CSV表格数据 | Base64编码的CSV文件二进制数据 |
| TEXT | 纯文本 | Base64编码的文本文件二进制数据 |

## 重要说明

### 1. rawData字段处理

- **rawData是Base64编码的字符串**，不是原始二进制数据
- 使用前需要先进行Base64解码，得到原始二进制数据
- 解码后的二进制数据根据`formatType`进行相应处理：
  - `IMAGE`：解码后是图片的二进制数据，可以保存为图片文件或直接用于图像识别
  - `PDF`：解码后是PDF文件的二进制数据，可以保存为PDF文件或进行PDF解析
  - `JSON`：解码后是JSON字符串，需要再次进行JSON解析
  - `CSV`：解码后是CSV文件的二进制数据，可以保存为CSV文件或进行CSV解析
  - `TEXT`：解码后是文本内容，可以直接使用

### 2. 数据使用建议

- **图片数据（IMAGE）**：可用于OCR识别、图像分析、AI视觉识别等
- **PDF数据（PDF）**：可用于PDF解析、文本提取等
- **JSON数据（JSON）**：可直接解析为结构化数据，用于数据分析
- **CSV数据（CSV）**：可用于表格数据分析和处理
- **文本数据（TEXT）**：可直接用于文本分析

### 3. 数据量说明

- 接口返回该用户**所有**的健康数据记录（按上传时间降序排列）
- 如果用户有多条相同`dataType`的数据，会全部返回
- 建议智能体根据`uploadTime`选择最新的数据进行处理
- 注意`fileSize`字段，大文件（如高清图片、PDF）的Base64字符串会很长

### 4. 时间格式

- `uploadTime`字段使用ISO 8601格式：`yyyy-MM-ddTHH:mm:ss`
- 示例：`2024-01-15T10:30:00` 表示2024年1月15日 10:30:00

## 使用示例场景

### 场景1：生成健康档案

1. 调用接口获取用户所有健康数据
2. 根据`dataType`分类处理不同类型的数据
3. 对`IMAGE`类型进行OCR识别，提取文字信息
4. 对`PDF`类型进行PDF解析，提取文档内容
5. 对`JSON`类型直接解析，获取结构化数据
6. 综合分析所有数据，生成健康档案

### 场景2：数据分析

1. 获取用户健康数据
2. 根据`uploadTime`筛选最近的数据
3. 对`WEARABLE`、`SLEEP`、`EXERCISE`等JSON数据进行趋势分析
4. 结合`REPORT`、`LAB`等医疗数据进行健康评估

---

## 注意事项

1. **Base64解码**：所有`rawData`都需要先Base64解码才能使用
2. **数据大小**：注意大文件的Base64字符串可能很长，需要合理处理内存
3. **字符编码**：文本类数据（JSON、CSV、TEXT）解码后注意字符编码（通常为UTF-8）
4. **空值处理**：如果某条记录的`rawData`为`null`，表示该记录没有实际数据
5. **时间排序**：数据已按`uploadTime`降序排列，最新的数据在前
